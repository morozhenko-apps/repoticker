# Feedback and contributions

RepoTicker is independently developed and maintained. Reproducible bug reports, platform compatibility findings and practical suggestions are welcome in [GitHub Issues](https://github.com/morozhenko-apps/repoticker/issues).

When reporting a bug, include your OS, app version and clear reproduction steps. Before attaching logs or screenshots, remove personal paths, local repository names, access tokens, private GitHub workflow details and other sensitive information. Report security vulnerabilities through GitHub's private security advisory process rather than public Issues.

Outside pull requests, patches and requests to join the upstream maintenance team are not accepted. You are welcome to fork and modify the project under [Apache License 2.0](LICENSE), while retaining the applicable copyright and [NOTICE](NOTICE) information. An independent fork should not be presented as an official RepoTicker release.
