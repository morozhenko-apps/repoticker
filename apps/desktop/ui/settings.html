Where to get the relay key

GitHub and RepoTicker do not issue relay keys. Host your own Cloudflare Worker, create RELAY_CLIENT_SECRET and enter the same secret using the native dialog. WEBHOOK_SECRET must be different. Without a deployed Worker URL, use Simple polling.
