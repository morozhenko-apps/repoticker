# RepoTicker direction

RepoTicker focuses on a small, responsive system-tray interface for managing many local Git checkouts and monitoring GitHub activity.

The product priorities are truthful repository state, explicit safe Git actions, useful workflow/runner information, native Linux/Windows behavior, localization and straightforward installation. New features should make these tasks simpler without hiding destructive actions or moving local data into an unnecessary cloud service.

Ideas and current work are tracked in [GitHub Issues](https://github.com/morozhenko-apps/repoticker/issues). This document does not promise features, dates or a release schedule.
