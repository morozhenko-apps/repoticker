## Stage 1–3: source, invariants, existing-test credit

- Real subject: `startGithubMonitoring` and its private `publish`, `refresh`, `invalidatePresentation` and `repoticker-card-shown` event listener.
- External dependencies only: `invoke`, `event.listen`, `collect`, `schedule`, fake `now`; no production use case is mocked.
- Existing `tests/hybrid-reconcile-schedule.test.mjs` covers native phase transitions, 15-minute safety reconciliation, task-hint coalescing and cooldown. `tests/github-monitor.test.mjs` covers a delayed successful publication followed by disconnection. These tests are **not** evidence for failed-publication recovery or card-shown dispatch.
- Invariants: no local Git mutation from remote monitoring; non-forced card-shown uses the existing refresh interval; one in-flight collector at a time; failed native publish cannot poison future queue entries; a prior account's result cannot be re-published after disconnect; untrusted exception strings do not reach UI.
